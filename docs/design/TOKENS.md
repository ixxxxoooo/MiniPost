# MiniPost UI 令牌与组件规则（流光 · 方案 C）

> **事实来源**：`docs/design/assets/tokens.css`（令牌）与 `app.css`（组件）。
> **代码对应**：`internal/gui/style.go`（调色板、控件）、`motion.go`（动效）、`projcolor.go`（项目色）。
> **同步校验**：`internal/gui/tokens_sync_test.go` 会逐项比对配色、语义色、时长、曲线、字号；改了一边必须同步另一边，否则测试失败。
> **流程**：任何 UI 改动 = 先改设计稿 → 再改代码 → 截图逐屏对比 → 通过后才交付。

## 1. 颜色

- 5 套配色（mist / ink / jade / amber / rose）× 亮 / 暗，基础令牌 12 个：
  `chrome`（标题栏/标签栏/状态栏）、`side`、`bg`（内容区）、`bg2`、`bd`、`bd2`、`fg`、`fg2`、`mu`、`ac`、`ach`、`acf`。
- 派生令牌只能由基础令牌计算，不得手写新色值：
  `ac-soft` 12%、`ac-soft2` 20%、`ac-line` 45%、`ac-glow` 42%、`ac-glow-s` 26%、`hover` fg 5.5%、`press` fg 9%、`hair` bd 62%、`glass` elev 84%。
- 语义色（方法、状态、JSON）亮暗各一套，方法色与状态色统一由 `methodColor` / `statusColor` 提供。
- 表单控件底：`bg2`；浮起控件顶部高光 `--hl`；强调色按钮用 `--grad-ac`（上方 16% 提亮的渐变）+ `--hl-ac`。

## 2. 项目主题色（与外观配色联动）

项目存的 hex 只提供**色相**，显示色 = `oklch(clamp(.56, L(ac-base), .8)  clamp(.11, C(ac-base), .17)  H)`，超出色域时降低彩度。
因此换配色或明暗模式时，所有项目头像、色块、标签强调线自动协调。设计稿 `pjc()`、Go 的 `adaptProjectColor` 必须一致。

## 3. 字体、字号、间距、圆角

- 字号：`xs 10 / sm 11 / base 12 / md 13 / lg 15 / xl 20`；代码、URL、数值用等宽字体。
- 间距（4 点网格）：`2 / 4 / 6 / 8 / 12 / 16`。
- 圆角：输入框 8、按钮 7、标准 `--r` 10、卡片 10、胶囊 = 高度 / 2；表格内类型小标 20 高 / 圆角 6。
- 阴影分层：`shadow-xs/sm/md/lg`；弹层用 `shadow-lg`，浮起小块（分段滑块、选中标签）用 `shadow-sm`。

## 4. 动效

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `dur-fast` | 120ms | 悬停、颜色变化 |
| `dur-base` | 180ms | 标签内容切换、浮层淡入 |
| `dur-slow` | 280ms | 列表行入场（逐行错开 24ms） |
| `dur-xl` | 380ms | Toast、徽章弹入 |
| 滑动指示器 | 420ms | 分段滑块、下划线、标签顶线（FLIP 滑动） |
| `ease-out` | `.2,.8,.2,1` | 通用 |
| `ease-emph` | `.22,1,.36,1` | 入场、指示器（先快后缓） |
| `ease-spring` | `.34,1.4,.64,1` | 开关旋钮、徽章（轻微过冲） |
| `ease-soft` | `.3,1.2,.5,1` | 对话框、卡片 |

入场关键帧：`popIn`（浮层/对话框：Y 6 + Scale .97）、`paneIn`（Y 4）、`rowIn`（Y 5）、`toastIn`（X 36 + Scale .96）。
指示器类控件（分段、下划线、标签顶线）**必须滑动**而不是瞬切；颜色变化统一 `Colors` 过渡。

## 5. 通用组件规范

### 表格（Params / Headers / form-data / urlencoded / 响应头 / Cookies 共用）
- 表头 28 高，淡底 + 下边框；列之间 1px 发丝竖线；首列 34 宽（复选框或序号）；末列为操作列。
- 行高 28，行间发丝线；名称/值用等宽字体；悬停整行 `hover` 底。
- Params / Headers / Body 上方有 34 高子栏（左：分类/类型切换；右：批量编辑等操作），与表格同底色融为一体。
- form-data 的“类型”列使用 `.tsel` 小标（Text / File），文件值显示 acSoft 小块：图片图标 + 文件名 + 大小。

### 分段控件（Body 类型、侧栏 / 响应切换）
- 灰色轨道（`bg2`）内一枚浮起的内容色胶囊（`bg` + `shadow-sm`）；切换时胶囊滑动到新选项，选中文字加粗。

### 请求标签栏（文件夹式标签）
- 条高 38，上内边距 6；选中标签与内容区同色、上圆角 10，下沿压住边框 1px，两侧有凹圆角，与内容融为一体；
- 选中标签顶部 2px 强调线（带光晕），切换时在标签间滑动；未选中标签之间是发丝分隔线，方法文字用等宽 + 方法色。

### 浮层（菜单、标签列表、对话框）
- **面板必须是不透明底**：MyGo 先画纯色层、后画渐变层，纯色面板会被其后的渐变元素（发送按钮等）透出，
  所以所有 `PopoverMenuButton` 都必须传 `a.menuOpts()`，对话框面板使用同色 Gradient。
- 圆角 12–14，`shadow-lg`，入场 `popIn`；遮罩用 `scrim`。

### 搜索框
- 占位符保持简短（如“搜索请求”），不要把所有可搜索字段罗列进去。

### 开关
- 32×19 胶囊，开启为强调渐变 + 柔光；旋钮 15px 白色圆，带 `ease-spring` 过冲滑动。

### 设置页
- 左侧导航：选中项左侧 3px 强调竖条（带光晕）；右侧分组标题（小号、弱色），每行 `settingsRow`（上下 8.5 内边距）；
  数字输入 78 宽，下拉 104 宽，主题卡片左对齐标签，备份行 34 高（数据库图标 + 等宽时间 + 大小 + 幽灵“恢复”按钮）。

## 6. 校验清单（交付前）

1. `go test ./internal/gui -run TestTokens` 通过（令牌与设计稿一致）。
2. 设计稿与 App 按同一场景截图（`MINIPOST_COMPARE_DIR` + `TestCompareScenes`），亮 / 暗至少各看一遍；
3. 所有弹出层（菜单、对话框、Toast、导入、快速打开）都与设计稿比对过。
